# CASI · Centro Acadêmico de Sistemas de Informação

**Universidade Federal de Viçosa · *Campus* Rio Paranaíba (UFV-CRP)** · Rio Paranaíba, Minas Gerais

O CASI representa os estudantes do curso de **Sistemas de Informação** da UFV-CRP.
Esta organização reúne os projetos abertos mantidos pelo centro acadêmico e pela
comunidade do curso: materiais de estudo, catálogo das disciplinas, modelos para
trabalhos acadêmicos e sistemas de eventos.

[![Discord](https://img.shields.io/discord/365311890420793346?label=Discord&logo=discord&style=flat-square)](https://discord.gg/aR6cGkG)

## O curso

Sistemas de Informação (SIP) na UFV-CRP, conforme a
[matriz curricular 2026 do Catálogo de Graduação da UFV](https://catalogo.ufv.br/matriz.php?campus=crp&complemento=*&curso=SIP&ano=2026):

| Carga horária | Horas |
|---|---|
| Disciplinas obrigatórias | 2700 |
| Disciplinas optativas | 360 |
| **Total** | **3060** |

Prazo de integralização: 4 anos (padrão) a 6,5 anos (máximo).

## Como contribuir

As contribuições são abertas a estudantes, egressos e professores.

1. Escolha o repositório e leia o `README.md` dele. Material de disciplinas (ementas,
   referências, resumos, listas) vai para
   [Sistemas-de-Informacao_UFV-CRP](https://github.com/CA-SI/Sistemas-de-Informacao_UFV-CRP).
2. Para sugerir ou relatar um problema, abra uma *issue* no repositório.
3. Para enviar uma alteração, faça um *fork*, crie uma *branch*, faça a mudança e abra
   um *pull request*.

Consulte a licença de cada repositório antes de reutilizar o material. O modelo
SRS preserva a GPL-3.0-or-later do projeto original; os demais projetos ativos
listados acima usam a licença MIT.
